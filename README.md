# Kindleスクショマン (kindle-auto-capture)

MacのKindleアプリで、ページの全画面撮影（スクリーンショット）とページめくりを自動化するAppleScriptツールです。

## どんなツール？（できること）
* **自動フルスクリーン**: 撮影が始まると自動で全画面になり、終わると元の大きさに戻ります。
* **1ページ目を逃さない**: 画面が開いてから「撮影 ➔ めくる」順番で動くので、最初のページもきれいに残せます。
* **右めくり・左めくり対応**: 和書（縦書き）と洋書（横書き）のどちらの本でも使えます。
* **保存先をFinderで選択**: 好きなフォルダをマウスでぽちぽち選べます。
* **続きから自動保存**: すでに画像がある場合は、一番大きな数字の続き（例: page_051.png）から連番で保存します。

## 使い方
1. Kindleアプリで撮りたい本を開きます。
2. このスクリプト（または書き出した.app）を実行します。
3. 画面の案内に沿って「めくる方向」「保存先フォルダ」「撮影枚数」を選びます。
4. 自動で撮影がスタートします！

## うまく動かないとき（注意点）
Macの「システム設定」>「プライバシーとセキュリティ」>「アクセシビリティ」で、このアプリ（またはスクリプトエディタ）に実行許可を出してください。

## 動作環境
* macOS
* Kindle for Mac
